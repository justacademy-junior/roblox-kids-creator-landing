# Roblox Kids Creator Landing Page

A playful, responsive landing page for the topic **From Playing to Creating: Kids Can Build Their Own Roblox Games**.

It explains Roblox Studio, Lua coding, Robux safety and a simple five-step path to a first game, with an interactive block builder in the hero section.

## Features

- Interactive "Mini world maker" (click or drag to paint blocks, works on touch)
- Flip cards for quick parent answers
- Staircase layout showing the path to a first game
- Sticky header, modern footer, fully responsive
- Accessible: keyboard focus styles, ARIA labels, reduced-motion support
- Single file, no build tools, no dependencies

## Run locally

Open `index.html` in any browser.

## Deploy on GitHub Pages

1. Push `index.html` and `README.md` to the repository root.
2. Go to **Settings > Pages**.
3. Under **Source**, choose the `main` branch and `/ (root)`.
4. Save, and your site goes live in a minute or two.

## Customize

Colors live in the `:root` block at the top of the CSS. Edit the text directly in `index.html`.
